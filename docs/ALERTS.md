# SOXLUSDT 盯盘

这是公开行情的异动提醒，处于试运行阶段。它不读取账户、仓位、杠杆或强平价，不自动交易，也不能代替交易所止损。没有人工标注的事件集，目前无法给出实盘误报率或漏报率。

## 默认规则

提醒默认关闭，可在「盯盘」面板启用。初始方向为防上涨，适合关注空单的不利波动；也可选择防下跌或双向。

| 参数 | 初始值 |
| --- | --- |
| 1 分钟涨跌下限 | 0.8% |
| 3 分钟涨跌下限 | 1.5% |
| 持续确认 | 5 秒，期间至少两笔新的真实执行样本 |
| 同向提醒冷却 | 5 分钟 |
| 自适应过滤 | 开启，3.5 倍稳健波动 |
| 最大买卖价差 | 0.3% |

开启自适应时，实际阈值取固定下限和波动阈值中的较大者。波动基准是候选窗口之前、最多 30 个连续已完成分钟收益的 `1.4826 × MAD`，至少需要 20 个收益；3 分钟窗口再乘 `√3`。最近 3 分钟不进入该基准。

实际阈值会显示在面板上，可能明显高于固定下限。减少提醒会带来更迟的确认，也可能过滤掉值得关注的上涨。关闭自适应只去掉波动过滤，其他数据质量与确认条件仍生效。

## 数据确认

- 使用实际成交按秒汇总的中位价，比较最近 5 秒与 1／3 分钟前的价格；不把 ticker 的重复 `last` 当作新成交。
- 检查成交和盘口时间、价差、成交覆盖及成交价与盘口的一致性。成交稀疏、过期或价差过大时暂停确认，并显示原因。
- 启动和断线恢复后重新积累实时成交，1 分钟规则至少预热 60 秒，3 分钟规则至少 180 秒。缓存 K 线只能提供波动背景，不能补足实时预热。
- 上涨、下跌分别冷却。已提醒的方向若继续扩大，距上次至少 30 秒且进一步变动达到 1 分钟固定下限，可再次提醒。

提醒提供窗口、价格变化、实际阈值和确认时间。这些条件描述已经发生的行情，不预测后续方向。

## 持续运行

开启「保持 Mac 唤醒」会阻止自动睡眠。手动睡眠、合盖、关机、应用退出或网络中断仍会停止监测；本机版不是服务器托管的全天保障。

系统通知不带声音，需要 macOS 允许通知，显示还受专注模式和系统设置影响。确认后的菜单栏警告会保留到标为已查看。连接或数据持续中断时，会单独提示监测中断，不把它算作价格异动。

分钟 K 线通过 OKX business WebSocket 的 `candle1m` 推送更新，并保留 REST 回填。传输连接与数据新鲜度分别检查；交易所“最快每秒更新”不等于每秒必有新数据。

提醒历史只保存在本机 `~/Library/Application Support/MarketBar/Alerts/events.jsonl`。界面展示最近记录，日志不自动删除。

## 验证范围

离线检查覆盖持续变化、孤立异常价、重复成交、过期数据、价差、断线预热、双向冷却与升级。实流检查验证订阅、预热和状态切换。这些检查不证明策略收益，也不证明实盘低误报。
