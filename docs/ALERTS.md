# 行情提醒

当前发布版内置一个监测对象，名称显示在铃铛面板顶部。提醒默认关闭。调整条件后，点击「启用提醒」或「保存设置」即可生效。

## 提醒条件

应用结合短时间内的价格变化与累计成交量，同时检查上涨和下跌。价格变动达到设定幅度，成交量超过近期均量的设定倍数，并持续满足确认条件后，应用会发出提醒。开启自适应过滤后，近期波动增大时价格门槛也会提高。

面板可调整价格门槛、成交量倍数、确认时间和同向提醒的冷却时间。数据过期、成交过少或买卖价差过大时会暂停判断。面板显示当前状态及原因。

## 通知与历史

确认后的提醒会标记在菜单栏。要接收静音横幅，请允许 MarketBar 发送 macOS 通知。横幅是否显示也受专注模式和系统设置影响。打开面板可以查看最近提醒及其触发原因。

监测在本机运行。应用退出、Mac 睡眠或断网时会中断，恢复后需要重新积累行情。可在设置中选择监测时保持唤醒。

提醒历史保存于 `~/Library/Application Support/MarketBar/Alerts/`，运行诊断位于 `~/Library/Application Support/MarketBar/Diagnostics/`。
