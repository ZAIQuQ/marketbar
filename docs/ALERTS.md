# SOXLUSDT 价量提醒

监测 OKX `SOXL-USDT-SWAP` 永续合约的放量上涨和放量下跌。它描述已经发生的行情，不预测趋势反转，也不读取账户或自动下单。

## 规则

新安装默认关闭提醒。启用后同时监测上涨和下跌，不需要选择持仓方向。

| 参数 | 默认值 |
| --- | --- |
| 本分钟涨跌下限 | 0.6% |
| 连续两分钟涨跌下限 | 1.0% |
| 成交量门槛 | 此前 20 个完整分钟均量的 3 倍 |
| 持续确认 | 5 秒，期间至少两笔新的真实成交 |
| 同向冷却 | 5 分钟 |
| 近期波动过滤 | 开启，3.5 倍稳健波动 |
| 最大买卖价差 | 0.3% |

每秒检查一次，本分钟相对前一分钟收盘价计算；连续两分钟相对两分钟前收盘价计算。使用当时已经收到的价格与累计成交量，满足条件便开始确认，不必等到整分钟结束。两分钟窗口的成交量与两倍分钟基准比较。不会按已过秒数外推整分钟成交量。

OKX 永续成交量单位是合约张数，与股票股数分开保存。每笔成交按交易 ID 去重，重复推送不会累计第二次。

波动过滤继续使用候选窗口之前、最多 30 个连续已完成分钟收益的 `1.4826 × MAD`，至少需要 20 个收益；最近 3 分钟不进入波动基准。实际价格门槛取固定下限与波动门槛中较高者，两分钟波动门槛乘 `√2`。成交量门槛与价格门槛必须同时满足。

面板可调整价格、量比、确认时间与冷却。量比是实际累计成交量除以既往完整分钟均量，因此分钟开头通常较低。参数偏严格会减少提醒，也可能迟报或漏报。

## 数据与通知

需要新鲜的实际成交、分钟流、有效买卖报价及完整历史基准。历史缓存不能单独触发提醒；启动和断线后要重新观察实时数据。交易所时钟在本机前方 3 秒以内使用一致容差，超过范围仍暂停判断。

上涨、下跌分别冷却。已提醒的方向若继续扩大，距上次至少 30 秒且进一步变动达到一分钟固定下限，可再次提醒。提醒包含本地时间、价格变动、成交量倍数、实际门槛和确认时长。

静默通知需要 macOS 允许横幅，仍受专注模式影响。菜单栏标记保留到点击已查看。连续数据中断 20 秒才提交健康通知；同一事件不重复通知，需要连续恢复 30 秒才结束事件，健康通知另有 5 分钟冷却。成交暂时稀疏不会直接被当成连接中断。

「保持 Mac 唤醒」阻止自动睡眠；合盖、手动睡眠、退出应用或断网仍会中断监测。

## 本地记录与排查

- 行情提醒：`~/Library/Application Support/MarketBar/Alerts/events.jsonl`。
- 运行诊断：`~/Library/Application Support/MarketBar/Diagnostics/`，有大小上限和轮转。
- 诊断记录频道状态、数值错误码、监测阶段及每分钟累计检查次数，不记录原始网络消息、账户、请求头或凭据。
- 面板显示本次可评估比例，便于区分规则没有触发和数据不足。通知日志中的 queued 仅表示系统接受提交，不证明横幅已经显示。

旧版方向设置升级为双向价量规则，原配置备份在本机设置 `MarketBar.alertConfiguration.beforeMinutePriceVolume`；启用状态、确认时间、冷却、波动过滤和唤醒设置保留。新规则保存后的自定义阈值不会被下次启动重置。

## 验证边界

离线检查覆盖重复成交、旧配置迁移、时间容差、数据失鲜、确认、冷却、历史量缺失和双向提醒。真实历史回放用于检查规则能否识别具体行情及其触发时刻；它无法重建当时的网络、盘口和通知投递。没有独立人工标注的事件集，不能据此给出实盘误报率或漏报率。
